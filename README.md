# VS Code GitHub Copilot 教程

GitHub Copilot 在 VS Code 中的功能学习教程，通过模块化课程帮助开发者掌握 AI 辅助编程技能。

## 📚 课程目录

#### [01 - WebSearch MCP 配置教程](./01-websearch-mcp-setup/)
配置 WebSearch MCP 扩展，为 GitHub Copilot 添加联网搜索能力
- MCP 基本概念和扩展安装
- 搜索引擎 API Key 配置
- 联网搜索使用方法

## 前置要求

- ✅ [Visual Studio Code](https://code.visualstudio.com/)
- ✅ [GitHub Copilot 扩展](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)
