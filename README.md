# VS Code GitHub Copilot 教程

## 📖 项目简介

这是一个全面的 GitHub Copilot 学习教程，专为 VS Code 用户设计。通过9个精心设计的模块化课程，帮助开发者从基础到进阶系统地掌握 AI 辅助编程技能。

每个课程都包含实际案例和动手实践，让您在真实场景中学会如何高效使用 GitHub Copilot 提升编程效率。

## � 快速开始

### 前置要求
- ✅ [Visual Studio Code](https://code.visualstudio.com/)
- ✅ [GitHub Copilot 扩展](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)
- ✅ GitHub 账户和 Copilot 订阅

### 使用方法
1. 克隆本仓库到本地
2. 按顺序学习各个模块
3. 跟随README说明进行实践练习
