# 09 - AI Instruction Writing with GitHub Copilot

## 课程目标

学习如何使用 GitHub Copilot 编写清晰、有效的指令文档，包括技术文档、用户手册、API 文档和开发指南。

## 什么是 AI 指令编写？

AI 指令编写是指利用人工智能助手来创建各种类型的指令性文档，包括：

- 技术文档和操作手册
- API 使用说明
- 代码注释和开发指南
- 用户操作指南
- 安装和配置说明

## 核心技巧

### 1. 结构化思维
使用清晰的层次结构来组织指令内容：

```markdown
# 主标题
## 概述
## 前置条件
## 详细步骤
### 步骤1：准备工作
### 步骤2：执行操作
## 故障排除
## 常见问题
```

### 2. 上下文驱动
提供足够的背景信息，让 Copilot 理解指令的目标受众和使用场景。

### 3. 渐进式完善
从大纲开始，逐步填充详细内容。

## 指令编写的最佳实践

### 1. 清晰的目标定义
- 明确指令的目标和受众
- 定义成功的标准
- 识别可能的障碍点

### 2. 逻辑性组织
- 按照时间顺序或重要性排列步骤
- 使用编号和子编号
- 提供清晰的导航结构

### 3. 具体而详细
- 使用具体的示例
- 包含必要的截图或代码片段
- 提供替代方案

## 实践练习

### 练习1：编写 API 使用指南

1. 打开 `api_guide.md` 文件
2. 使用 Copilot 生成 RESTful API 的使用说明
3. 包含认证、请求格式、响应处理等内容

### 练习2：创建安装指南

1. 打开 `installation_guide.md` 文件
2. 为一个开源项目编写详细的安装说明
3. 覆盖不同操作系统和环境

### 练习3：编写代码注释模板

1. 打开 `comment_templates.py` 文件
2. 使用 Copilot 生成标准化的代码注释模板
3. 包含函数、类和模块的注释规范

## 指令类型和模板

### 1. 操作指南模板
```markdown
# [操作名称] 指南

## 概述
[简要说明操作的目的和结果]

## 前置条件
- [列出必要的前置条件]
- [包含权限要求]
- [必要的工具或环境]

## 操作步骤
1. [第一步的详细说明]
2. [第二步的详细说明]
...

## 验证结果
[如何确认操作成功]

## 故障排除
[常见问题和解决方案]
```

### 2. API 文档模板
```markdown
# API 端点名称

## 描述
[API 的功能说明]

## HTTP 方法和 URL
```
METHOD /api/endpoint
```

## 请求参数
| 参数名 | 类型 | 必需 | 描述 |
|--------|------|------|------|

## 请求示例
[提供具体的请求示例]

## 响应格式
[响应数据的结构说明]

## 错误代码
[可能的错误情况和处理方式]
```

## 使用 Copilot 的技巧

### 1. 上下文设置
在文件开头提供清晰的上下文：
```markdown
<!-- 这是一个为初学者编写的 Docker 安装指南 -->
<!-- 目标用户：没有容器化经验的开发者 -->
<!-- 操作系统：Ubuntu 20.04 LTS -->
```

### 2. 渐进式提示
使用结构化的注释来引导 Copilot：
```markdown
<!-- 步骤1：下载安装包 -->
<!-- 步骤2：验证安装包 -->
<!-- 步骤3：执行安装 -->
<!-- 步骤4：验证安装结果 -->
```

### 3. 示例驱动
提供一个完整的示例，让 Copilot 基于此生成类似的内容。

## 质量检查清单

- [ ] 目标和受众明确
- [ ] 步骤逻辑清晰
- [ ] 包含必要的前置条件
- [ ] 提供具体的示例
- [ ] 包含错误处理和故障排除
- [ ] 语言简洁易懂
- [ ] 格式一致规范
