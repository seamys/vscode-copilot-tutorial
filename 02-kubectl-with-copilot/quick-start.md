# 快速入门指南

本指南帮助你快速开始使用 GitHub Copilot Chat 管理 Kubernetes。

## 🚀 5分钟快速体验

### 1. 打开 Copilot Chat
- 按 `Ctrl+Shift+I` (Windows/Linux) 或 `Cmd+Shift+I` (Mac)
- 或点击左侧边栏的聊天图标

### 2. 试试这些对话
复制以下文本到 Chat 中，体验 AI 助手的能力：

```
我想查看集群中所有运行异常的 Pod，请给我相应的 kubectl 命令
```

```
帮我生成一个命令来查看集群节点的资源使用情况
```

```
我需要获取某个 Pod 的日志，最近100行，应该怎么写命令？
```

### 3. 进阶体验
尝试更复杂的需求：

```
我想要一个表格显示所有 Pod 的名称、状态、节点和 IP 地址
```

```
帮我诊断一个一直重启的 Pod，需要检查哪些方面？
```

## 💡 实用技巧

### 有效提问的方式
- ✅ "我想查看集群中内存使用最高的前10个 Pod"
- ✅ "帮我生成一个命令来删除所有已完成的 Job"
- ❌ "kubectl 命令" (太模糊)

### 充分利用上下文
- 把命令执行结果贴回给 Chat，让它帮你分析
- 在同一个会话中持续对话，AI 会记住上下文
- 询问最佳实践和安全建议

### 学习导向的提问
- "这个命令的每个参数是什么意思？"
- "有没有更好的方法来实现这个需求？"
- "这样操作有什么潜在风险？"

## 🎯 学习路径建议

1. **基础操作** (15分钟)
   - 查看资源状态
   - 获取详细信息
   - 查看日志

2. **监控诊断** (20分钟)
   - 资源使用监控
   - 故障排查流程
   - 事件分析

3. **高级功能** (25分钟)
   - 自定义输出格式
   - 批量操作
   - 复杂查询

4. **最佳实践** (持续)
   - 安全意识
   - 性能优化
   - 自动化脚本

- 探索 Copilot Chat 的其他 Kubernetes 相关功能
