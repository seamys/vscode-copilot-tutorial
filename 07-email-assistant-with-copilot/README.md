# 07 - Email Assistant with GitHub Copilot

## 课程概述

本课程展示如何使用 GitHub Copilot 的自定义聊天模式和提示词来构建智能邮件助手，帮助处理日常邮件沟通任务。

## 学习内容

### 1. 邮件回复助手 (email.chatmode.md)
- **功能**: 自动起草简洁、自然、友好的邮件回复
- **特点**: 
  - 双语支持（中英文）
  - 智能分析邮件线程
  - 自动选择合适的语调和长度
  - 遵循企业沟通规范

### 2. 邮件时间线分析 (email-timeline.prompt.md)
- **功能**: 整理和总结长邮件线程
- **特点**:
  - 按时间顺序组织邮件
  - 提取关键信息和决策
  - 生成行动项清单
  - 专业格式化输出

## 实际应用

1. **邮件回复自动化**: 快速生成专业、友好的邮件回复
2. **邮件线程管理**: 将复杂的邮件对话整理成清晰的时间线和摘要
3. **高效沟通**: 节省邮件处理时间，提高沟通效率

## 使用方法

1. 将邮件内容提供给相应的聊天模式或提示词
2. Copilot 会根据配置自动分析和处理
3. 获得格式化的回复或摘要结果

这个课程展示了如何通过自定义配置让 GitHub Copilot 成为强大的邮件处理助手。
